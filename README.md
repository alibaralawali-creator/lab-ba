## 🇫🇷 Installation

**Configuration requise :** Windows 10 ou 11, 64 bits. Fonctionne sans internet.

1. **Télécharger** : ouvrez la page des versions, puis cliquez sur le fichier **`Lab-BA-Setup-x.y.z.exe`** de la dernière version (environ 96 Mo).
   - Chine : https://gitee.com/alibaralawali/lab-ba/releases
   - Autres pays : https://github.com/alibaralawali-creator/lab-ba/releases/latest
2. **Lancer** le fichier téléchargé.
3. Si Windows affiche **« Windows a protégé votre ordinateur »** : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**. (Le logiciel n'est pas signé numériquement, c'est normal.)
4. **Acceptez la licence**, choisissez le dossier d'installation, puis **Installer**.
5. Ouvrez **Lab BA** depuis l'icône du Bureau ou le menu Démarrer.

**Mises à jour :** automatiques. Quand une nouvelle version sort, un message apparaît en bas à droite du logiciel : cliquez sur **Mettre à jour**, puis **Redémarrer pour installer**. Vos projets sont conservés.

**Vos projets** sont enregistrés dans `Documents\Lab BA\Projets`.

**Désinstaller :** Paramètres Windows → Applications → Lab BA → Désinstaller (vos projets ne sont pas supprimés).

> Les résultats sont fournis à titre indicatif : toute note de calcul destinée à un projet réel doit être vérifiée par un ingénieur qualifié.

## 🇨🇳 安装说明

**系统要求：** Windows 10 或 11（64 位）。无需联网即可使用。

1. **下载**：打开发行版页面，点击最新版本中的 **`Lab-BA-Setup-x.y.z.exe`**（约 96 MB）。
   - 中国：https://gitee.com/alibaralawali/lab-ba/releases
   - 其他国家：https://github.com/alibaralawali-creator/lab-ba/releases/latest
2. **运行**下载的文件。
3. 如果 Windows 提示 **"Windows 已保护你的电脑"**：点击 **更多信息**，然后点击 **仍要运行**。（软件没有数字签名，属正常现象。）
4. **接受许可协议**，选择安装目录，点击 **安装**。
5. 从桌面图标或开始菜单打开 **Lab BA**。

**更新：** 自动更新。有新版本时，软件右下角会出现提示：点击 **更新**，再点击 **重启以安装**。项目不会丢失。

**项目文件**保存在 `文档\Lab BA\Projets`。

**卸载：** Windows 设置 → 应用 → Lab BA → 卸载（项目文件不会被删除）。

> 计算结果仅供参考：用于实际工程的计算书必须由合格工程师复核。
